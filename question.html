Posez votre question

Un professeur virtuel vous répond en s'appuyant uniquement sur des guides de grammaire reconnus, et illustre quand il le peut avec une ligne d'Aimyon déjà vérifiée sur ce site.

Clé d'API Anthropic

Les réponses sont produites par Claude, le modèle d'IA d'Anthropic. Le site n'a pas de serveur : chaque question part directement de votre navigateur vers Anthropic, avec votre propre clé d'API. Elle n'est envoyée nulle part ailleurs.

Créez une clé sur platform.claude.com ↗. Chaque question est facturée sur votre compte Anthropic (tarif du modèle Claude Opus 5.5 : 4 $ par million de mots-jetons lus, 20 $ par million écrits, plus un petit supplément par recherche web). Le coût estimé s'affiche sous chaque réponse.

Comment le professeur évite d'inventer

  • Sources limitées. Il ne peut chercher que dans quatre guides : Tae Kim, Tofugu, Imabi et Bunpro. Chaque affirmation renvoie à la page consultée.
  • Paroles vérifiées. Il ne cite que les extraits d'Aimyon déjà contrôlés sur ce site. Une citation qui n'y figure pas est signalée sous la réponse.
  • Franchise. Quand les sources ne couvrent pas la question, il est tenu de le dire plutôt que de compléter de mémoire.

Cela réduit le risque d'erreur sans le supprimer : vérifiez les points importants dans les sources citées.
